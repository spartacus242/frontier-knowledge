## Restatement (my words)

HEADLINE: When you train neural networks with more data and with more parameters, does test error come down along a power-law curve that can be forecast from small runs, and does the same kind of curve hold for unrelated tasks (vision, text, translation, speech)?

OPERATIONAL TEST: Train fresh networks on four named public tasks (ImageNet-1k width-varied ResNets; One Billion Word LSTM; WMT En-De attention seq2seq; LibriSpeech 960 h recurrent acoustic model) on a grid of 8 nested data fractions 2^0..2^-7 by 5 widths (>= 1.5 decades of parameters), one fixed-budget random search per cell, 3 seeds. Fit eps = c + a n^-alpha + b m^-beta on the cells with n <= 2^-3 and the 3 smallest widths; predict the remaining cells. YES iff in all four tasks the median relative prediction error on held-out cells is <= 10% AND the form beats an additive-logarithmic and an additive-exponential rival on held-out error. Otherwise NO, naming the failing task and the better form.

## DEPTH CHECK: Pass

Object test: "The answer would be a fact about how the held-out error of trained neural networks depends on the number of training examples and the number of parameters" - the intrinsic behaviour of a class of computations / trained models as things that behave. On the pass list; the blank does not need a dataset name to be true (the four corpora are stimuli). Deletion test: if every paper and protocol vanished, the learning algorithms, architectures and data-generating tasks would still fix the dependence - the answer survives. Rows test: one row is one freshly trained network at one (task, n, m, seed) cell. Clause check: none of (a)-(e); nothing published is re-analysed, no published number is moved. Variation check: what must differ for the answer to differ is the networks' learning behaviour on the tasks. Residual risk, same as the record states: eps(n,m) is defined relative to a tuning budget (P1), so a determined reader could say a protocol co-determines the answer; I judge that a nuisance, not the estimand. A Pass is not a finding in the candidate's favour.
