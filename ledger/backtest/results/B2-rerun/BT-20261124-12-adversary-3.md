## Restatement, in my own words

**Headline layer (as carried from the ranker):** can a small number of transcription factors, delivered into an adult cell that has already become one specialised thing, put that cell back into the embryo-like state from which any tissue can be made?

**Operational layer (version 2, the wording now in force):** start from one clonally derived cell that is terminally differentiated by a criterion fixed in advance and that carries a heritable tag proving it was somatic (a V(D)J/TCR rearrangement, or a label driven by a terminal-differentiation promoter). Stably integrate up to ten sequence-specific transcription factors, drawn singly and in combination from a list generated by a rule over pre-2001 print. Ask whether **any clone arising from such a donor** shows all five of: >~20 passages of self-renewal; the donor tag; endogenous pluripotency loci transcribed from their own promoters with the transgenes dispensable; loss of the donor programme; and three germ layers in a teratoma plus chimaera contribution including germ line. One such clone = YES. Failure of every combination actually run = a NO bounded by exactly that list.

So the headline asks a possibility question about cells; the operational test asks whether a qualifying clone can be *recovered* from a transduced marked donor.
