# Security

## What to report

- A way to get a record merged that the checker should have refused.
- A way to make the workflows in `.github/workflows/` run code from a pull request, leak a token, or write somewhere
  they should not.
- A way to take a unit that checks your own record, or to fill a unit's slots from one person.
- Anything in the repository that should not be public: a credential, or personal information about someone.

## How to report

Use **Security, Report a vulnerability** on this repository's GitHub page. That opens a private report that only the
maintainers see. Please do not open a public issue or pull request for a security problem.

You will get an answer from a maintainer listed in [MAINTAINERS](MAINTAINERS). There is one maintainer today, so
allow a few days.

## What is not a security problem

A wrong result, a bad citation or a question that should have been rejected is ordinary work for the swarm. Take the
unit that checks it, or start a Discussion.
