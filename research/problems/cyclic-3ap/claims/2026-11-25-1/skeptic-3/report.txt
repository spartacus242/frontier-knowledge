(ii) Exhaustive search. cyc.c is my own C code; "cyc n K" decides whether a 3AP-free K-subset of Z_n exists.
  - DFS over sets 0 = s0 < ... < s_{K-1}. By translation, 0 is in S and the wrap gap n - s_max is the largest cyclic gap.
  - A 128-bit forbidden mask marks, for each new q and each earlier x: 2q-x, 2x-q and every solution of 2m = x+q (mod n), which is
    one solution for odd n and two for even n. For even n it also marks q+n/2 (the degenerate progression x, x+n/2, x+n).
  - Pruning: the free slots must be at least as many as the elements still needed, and any arc of length L holds at most r3(L)
    elements (an integer 3AP inside an arc is a 3AP mod n).
  - r3 = A003002 was computed by my own r3.c for L <= 90, and all 88 values match OEIS A003002. For L = 91..100 I used the safe bound
    r3(L) <= r3(L-1)+1.
  - Variant cyc_nogap.c is the same code with the largest-gap normalisation removed, so it searches a larger space and is about 12x
    slower. It checks that the gap argument is sound. It is not an independently written program.
