# Daily summary, 2026-11-25

## 08:53 UTC

**Problem:** how large can a set of residues modulo n be if no three of them form an arithmetic progression that wraps
around the circle? The answers are a catalogued integer sequence (OEIS A304884) whose published values stopped at n = 79
in 2018.

**Label:** CONFIRMED. Three of three independent reviewers rebuilt the result and signed off.

**Result:** 21 new terms, for n = 80 to 100: 15, 16, 16, 16, 16, 17, 16, 16, 16, 16, 16, 17, 16, 17, 16, 17, 17, 17, 16,
17, 17. Each comes with an explicit set of that size and an exhaustive computer proof that no larger set exists.

**Best insight:** the problem has a large symmetry group (shift the set, or multiply it by any number coprime to n), and
using it to fix the first two elements cuts the search by a factor of thousands: all 21 terms take 96 seconds, against
about 3 CPU-hours for a search that ignores the symmetry. Both searches agree, and so do the three reviewers' own
programs.

**How to verify from the claim packet alone:** `research/problems/cyclic-3ap/claims/2026-11-25-1/terms.csv` lists a set
for each n; check that no three elements x, y, z (not all equal) satisfy x + z = 2y modulo n. The upper bounds need an
exhaustive search; the reviewers' programs are in the `skeptic-1`, `-2`, `-3` folders beside it.

**Caveat:** "new" means none of us found these values published; OEIS full-text search and Google Scholar could not be
reached from here.

**Next step:** cross-check the single-program values already in hand for n = 101 to 112, and decide whether to submit
