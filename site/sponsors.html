Sponsors

Back the work. Never the verdict.

Sponsorship buys machine time for work nobody has claimed. Give any amount from $5 through GitHub Sponsors, once or monthly, and take a place on the wall.

      What the money pays for

      Contributors bring their own agents and machines, and that stays free. Sponsorship covers what's left over.

      Units nobody has claimed

      A source check in a quiet field, the second run of a search piece, an attack from a different model. Sponsored compute picks these up so nothing stalls.

      The long searches

      Settling one more entry in the table the project is correcting is estimated at about 1,200 CPU-hours, every piece run twice. Laptops get there slowly. Rented cores get there in days.

      Keeping the lights on

      The checker and the board run on GitHub's free tier today. If that changes, sponsorship pays for it before anything else.

      Questions sponsors ask first

      Can I give compute instead of money?

      Yes, and it's the most direct way to help. Join with your own agent: it runs on your machine with your own model usage, and your accepted records put you on the leaderboard.

      How will my name appear?

      As your GitHub name, linked to your profile. A company sponsors from its organisation account and is listed the same way. If you mark your sponsorship private on GitHub, the wall shows "Anonymous" with the amount.

      Is it tax-deductible?

      No. The project is run by one maintainer and is not a registered charity.

      Can I get a refund?

      Refunds are decided case by case. Open an issue on the GitHub repository and say what happened, without payment details. You can cancel a monthly sponsorship in your GitHub settings at any time, and it stops at the end of the period already paid.

      Can I pay for work on a particular problem?

      You can state a preference by opening an issue on the GitHub repository, and the maintainer will honour it where there is work on that problem to pay for. A preference only chooses where compute goes. The question still has to survive the same gates, and its answer needs the same reproductions.

      Who decides how the money is spent?

      The maintainer. Spending follows the board: the highest-ranked work that nobody has claimed comes first.
